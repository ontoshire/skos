# SKOS — Simple Knowledge Organization System

**A mirror. Not maintained by Ontoshire.**

Published by the W3C. This repository contains **no RDF** — only an `ontoshire.ttl`
naming the publisher's own canonical URL, which Ontoshire fetches unchanged
when a version is published.

| | |
|---|---|
| Source | <https://www.w3.org/2009/08/skos-reference/skos.rdf> |
| Ontology IRI | `http://www.w3.org/2004/02/skos/core` |
| Licence | [W3C Document Licence](https://www.w3.org/copyright/document-license-2023/) |

Mirrored so the ontology is discoverable and resolvable alongside others, and
so dependencies on it can be followed. The bytes are always the publisher's,
and the published version records a checksum of exactly what was fetched.

If you maintain this ontology and would rather it were not mirrored here,
[tell us](mailto:enquiries@ontoshire.com) and it will be removed.
